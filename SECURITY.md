# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a security problem.

Report it privately to security@stealthmark.io (and via GitHub private vulnerability reporting once it is enabled on this repository). Include:

- the package and version (for example `@stealthmark/core` 0.1.0),
- a description of the issue and its impact,
- steps or a minimal proof of concept to reproduce it.

We will acknowledge the report, investigate, and coordinate a fix and disclosure with you. This is a small project, so there is no guaranteed response time.

## Scope

This repository contains the open-source SDK packages: `@stealthmark/core`, `@stealthmark/next`, `@stealthmark/express` and `@stealthmark/cli`. Issues in the hosted StealthMark service can be reported to the same address.

## Supported versions

The SDK is published to npm. Only the latest published version and the latest commit on `main` are supported.
